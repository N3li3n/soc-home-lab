# Agent Configs

Конфигурации Wazuh-агентов и Sysmon.

## Файлы

 `ossec-ubuntu.conf` | Ubuntu (Wazuh Manager) | Конфиг Wazuh Manager |
 `ossec-win11.conf` | Windows 11 | Wazuh-агент + сбор Sysmon, Security, PowerShell |
 `ossec-kali.conf` | Kali Linux | Wazuh-агент на Kali |
 `sysmonconfig.xml` | Windows 11 | Sysmon config: ProcessCreate, ProcessAccess (LSASS), NetworkConnect, CreateRemoteThread |
