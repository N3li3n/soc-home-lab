# Sigma Rules (Неделя 2)

## Что такое Sigma

Sigma — универсальный формат правил детектирования, который можно конвертировать в запросы для разных SIEM.

## Инструменты

- **sigma-cli** — конвертация в Lucene/EQL (Security Onion).
- **SigWaz** — конвертация в Wazuh XML.

## Правила

| Правило | Техника MITRE | Lucene | Wazuh XML | Wazuh ID |
|---------|--------------|--------|-----------|----------|
| `T1003.001-lsass-access.yml` | T1003.001 | ✅ | ✅ | `100500`, `100501` |
| `T1110-ssh-bruteforce.yml` | T1110 | ❌ | ✅ | `100600`, `100602` |
| `T1059.001-powershell.yml` | T1059.001 | ✅ | ✅ | `100601` |

## Lessons Learned

- SigWaz генерирует ID `900000` — нужно **вручную** менять на уникальные.
- `if_sid` для Sysmon Event ID 1 = `61603`, для Event ID 10 = `61609`.
- Wazuh **не допускает** `</group>` внутри `<rule>`.
- **Всегда** проверяйте баланс тегов через `grep -c`.
